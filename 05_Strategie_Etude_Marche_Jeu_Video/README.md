# Stratégie & Étude de Marché - "Lancement d'un Jeu Vidéo"

* **Contexte / Besoin métier :** Un studio de développement cherche des recommandations pour le lancement d'un nouveau jeu AAA d'ici 2026. Besoin peu cadré, grande autonomie analytique requise.
* **Données :** Base de ventes historique (1980-2020), scores Metacritic, couplées à une analyse de marché externe.
* **Démarche :** Modélisation en schéma en étoile (Filtres 1:*). Croisement de la donnée quantitative historique avec une veille qualitative via une matrice PESTEL (évolutions socio-économiques).
* **Résultats + Impact :** Recommandation stratégique précise (développement d'un jeu Action/RPG sur PC/PS5 ciblant un public adulte), prouvant que la donnée seule est insuffisante si non couplée au contexte métier.
* **Limites + Prochaines pistes :** La BDD s'arrête en 2020. **Piste d'amélioration :** Automatiser un script de Web Scraping (Python/BeautifulSoup) sur les plateformes comme Steam/Twitch pour des datas en temps réel.
