# Machine Learning & Prédiction Immobilière - "Les Plus Beaux Logis de Paris"

* **Contexte / Besoin métier :** Une agence immobilière de luxe souhaite analyser l'évolution du marché et classifier automatiquement de nouveaux biens anonymes pour estimer leur valeur.
* **Données :** Historique massif de transactions immobilières (2017-2021).
* **Démarche :** Analyse univariée/bivariée (Python). Préparation via One-Hot Encoding. Déploiement d'une IA (Modèle non-supervisé Clustering K-Means ciblant la variable prix/m²).
* **Résultats + Impact :** Le modèle a segmenté la base avec une précision mathématique, identifiant la frontière entre biens standards et prestige. Vulgarisation du taux d'erreur au client en pourcentage plutôt qu'en score mathématique abstrait.
* **Limites + Prochaines pistes :** Modèle basé uniquement sur la surface et le prix au m². **Piste d'amélioration :** Intégration d'Open Data géographique (proximité métro/écoles).
